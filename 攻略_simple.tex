\section{行程总览}

\begin{verbatim}
Day 0：各地 → 贵阳（集合取车）
Day 1：贵阳 → 织金洞 → 盘州
Day 2：盘州 → 乌蒙大草原 → 北盘江大桥 → 兴义
Day 3：兴义 → 万峰林
Day 4：兴义 → 马岭河峡谷 → 万峰湖
Day 5：兴义 → 贞丰 → 格凸河
Day 6：格凸河 → 坝陵河大桥 → 平塘天眼
Day 7：平塘 → 贵阳 → 各地
\end{verbatim}

\subsection{基本信息}
\begin{itemize}
\item 总里程：约1500km
\item 日均车程：3-4小时
\item 人均预算：约5000元（基础版）
\item 最佳时间：7-8月
\end{itemize}

\section{每日详细行程}

\subsection{Day 0：各地 → 贵阳}
\begin{itemize}
\item 各地航班到达贵阳
\item 机场取车
\item 晚上车队准备会
\end{itemize}

\subsection{Day 1：贵阳 → 织金洞 → 盘州}
\begin{itemize}
\item 织金洞游览3.5小时
\item 洞内16度，带薄外套
\end{itemize}

\subsection{Day 2：盘州 → 乌蒙大草原 → 兴义}
\begin{itemize}
\item 乌蒙大草原，海拔2800米
\item 北盘江大桥，世界第一高桥565米
\end{itemize}

\section{预算明细}
人均约5000元，包含：大交通1500、租车油费600、住宿700、餐饮700、门票800、其他700。

\section{行前准备清单}
\begin{itemize}
\item 凉鞋/溯溪鞋（必带！漂流用）
\item 薄外套+厚外套（洞里16度，山上15度）
\item 雨衣
\item 肠胃药（吃辣必备）
\item 防晒霜、帽子、墨镜
\end{itemize}

\section{车队自驾规则}
\begin{enumerate}
\item 头车尾车制度，2台车
\item 每2小时休息换人开车
\item 贵州高速多隧道，提前减速
\item 盘山路不超车，弯道鸣笛靠右行
\end{enumerate}

\section{景点避坑指南}
\begin{itemize}
\item 织金洞：不要跟团，自己慢慢逛3.5小时
\item 乌蒙：不要压草坪，罚款500
\item 万峰林：不要进收费村寨，都是坑
\item 格凸河：下午去，4点看蜘蛛人表演
\end{itemize}

\section{实用信息}
\begin{itemize}
\item 导航用高德地图
\item 贵州菜很辣，不能吃辣提前说
\end{itemize}
